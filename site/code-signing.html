Πολιτική υπογραφής κώδικαCode signing policy

Δωρεάν υπογραφή κώδικα από το SignPath.io, με πιστοποιητικό από το SignPath Foundation (η αίτηση εξετάζεται).Free code signing provided by SignPath.io, certificate by SignPath Foundation (application under review).

Τι υπογράφεταιWhat is signed

  • Μόνο το πρόγραμμα εγκατάστασης για Windows (BlueGuardian-AI-Setup.exe) από τις επίσημες εκδόσεις.Only the Windows installer (BlueGuardian-AI-Setup.exe) from the official releases.
  • Χτίζεται αυτόματα από τον δημόσιο κώδικα με GitHub Actions. Κανένα αρχείο δεν υπογράφεται χειροκίνητα.It is built automatically from the public source code with GitHub Actions. No file is signed by hand.

Ρόλοι ομάδαςTeam roles

  • Συγγραφείς και ελεγκτές κώδικα: η μαθητική ομάδα BlueGuardian AI, μέσω του λογαριασμού GitHub blueguardianai.Committers and reviewers: the BlueGuardian AI student team, through the GitHub account blueguardianai.
  • Εγκρίνοντες: τα ίδια μέλη. Κάθε υπογραφή εγκρίνεται χειροκίνητα πριν δημοσιευτεί μια έκδοση.Approvers: the same members. Every signing request is approved by hand before a release is published.
  • Όλοι οι λογαριασμοί χρησιμοποιούν έλεγχο ταυτότητας δύο παραγόντων.All accounts use two-factor authentication.

ΑπόρρητοPrivacy

Το πρόγραμμα δεν στέλνει πληροφορίες σε άλλα συστήματα, εκτός αν το ζητήσει ο χρήστης. Οι εξαιρέσεις: οι χάρτες φορτώνουν από το OpenStreetMap και την Esri, και μια καταγραφή δημοσιεύεται μόνο όταν πατήσετε «Κοινοποίηση». Λεπτομέρειες στη σελίδα Απόρρητο.This program will not transfer any information to other networked systems unless specifically requested by the user. The exceptions: maps load from OpenStreetMap and Esri, and a visit is only published when you press "Share". Details on the Privacy page.
